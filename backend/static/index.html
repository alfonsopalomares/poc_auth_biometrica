PoC de Verificación Biométrica Adaptativa

Bienvenido al panel de administración de la Prueba de Concepto (PoC).

Este sistema demuestra un flujo de autenticación multimodal que combina biometría de voz y de gestos. Utilice el menú superior para navegar por las diferentes secciones:

  • Crear Usuario: Permite dar de alta nuevos usuarios en el sistema.
  • Gestión de Voz: Permite registrar y verificar la huella de voz de un usuario.
  • Gestión de Gesto: Permite registrar y verificar el patrón gestual de un usuario.
