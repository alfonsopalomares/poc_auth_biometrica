PoC de Verificación Biométrica Adaptativa

Bienvenido al panel de administración de la Prueba de Concepto (PoC).

Este sistema demuestra un flujo de autenticación multifactor (MFA) que combina biometría de voz y de gestos. Utilice el menú superior para navegar por las diferentes secciones:

  • Crear Usuario: Permite dar de alta nuevos usuarios y configurar sus factores de autenticación (ej. 1 o 2 factores).
  • Gestión de Voz: Permite registrar un perfil de voz para un usuario. La verificación se realiza en el panel de MFA.
  • Gestión de Gesto: Permite registrar un patrón gestual para un usuario. La verificación se realiza en el panel de MFA.
  • Test MFA: Simula un flujo de autenticación multifactor, iniciando una sesión y permitiendo verificar los factores requeridos para obtener acceso.
